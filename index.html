What it provides

A practical visual organization system

Personal visual identity

Add meaningful Unicode emojis and familiar text colours to bookmark folders.

Faster organization

Select individual items or ranges, sort four ways, search destinations, and drag folders into folders.

Safer deletion

Move items to FolderMoji Trash, restore selected items, and receive warnings before large permanent operations.

Private suggestions

Folder suggestions and preferences are calculated and stored on the device—not sent to an AI service.

Duplicate awareness

See each item’s location and receive a warning before creating a matching folder name.

Standard bookmarks

FolderMoji works with Chrome bookmarks; Unicode emojis remain part of synchronized folder names.

Try FolderMoji

Install the testing release

  1. Download and extract FolderMoji-v1.3.10.zip.
  2. In desktop Chrome, open chrome://extensions.
  3. Enable Developer mode.
  4. Select Load unpacked.
  5. Select the extracted FolderMoji-v1.3.10 folder containing manifest.json.
  6. Open chrome://bookmarks.
Testing notice: This release is not yet distributed through the Chrome Web Store. Review the included licence, privacy notice, and permissions before installation.

Privacy and permissions

FolderMoji requests Chrome’s bookmarks permission to organize bookmarks and storage permission to retain local settings. It contains no advertising or analytics and does not transmit bookmark titles, URLs, browsing history, or emoji selections to Paul Williams or an external AI service.
